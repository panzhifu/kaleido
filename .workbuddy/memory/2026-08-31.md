## 数据模型设计 v1 定稿（2026-08-31）
- Document = Scene 对象树（Group / Pixel / Vector / Text 四节点）+ Selection（灰度蒙版）+ History + Timeline + ColorProfile + Resources。
- 决策：矢量 = 节点式路径（锚点+控制点）；动画 = 双轨（逐帧手绘 Krita 式 + 属性关键帧 AE 式）；瓦片固定 256；**调整层 → 插件效果链**（Node.effects / EffectBinding，宿主只定义 Effect 契约，v1 内置 1-2 示例效果）。
- 设计文档：docs/architecture-data-model.md。
